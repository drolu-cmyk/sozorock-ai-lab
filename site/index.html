What the Lab does

Learn by solving a real problem.

Participants bring a task, workflow, or service need. The Lab helps them understand the problem, build a practical system, test it, and use it responsibly.

Individuals

Build practical AI capability around real work.

Small businesses

Improve recurring operations without a large technical team.

Community institutions

Use AI carefully to strengthen administration and service delivery.

The method

Start with the work, not the tool.

Every project follows a simple path from need to responsible use.

01

Understand

Define the work, users, data, and risk.

02

Build

Create a useful system around the real need.

03

Test

Use it, find failures, and improve it.

04

Deploy

Place it into an appropriate working setting.

05

Govern

Set boundaries, oversight, and accountability.

06

Show

Document what changed and what comes next.

Program

Practical, focused, and no cost.

No prior technical background is required for every pathway. Selected applicants receive the schedule, format, and project expectations before enrollment.

Cost

Participation is offered at no cost.

Format

In person, virtual, or hybrid depending on the cohort.

Commitment

Attend consistently and complete real project work.

Selection

Based on need, readiness, fit, and responsible project scope.
